# dedupcommando.github.io

The DedupCommando website moved to https://dedcom.dequzzy.io/. Its source is
[dedupcommando/site](https://github.com/dedupcommando/site); the program itself lives in
[dedupcommando/DedupCommando](https://github.com/dedupcommando/DedupCommando).

This repository only keeps the old address working. `redirect/` holds one page for every address the
site had here; each forwards to the same page on the new site, and `404.html` forwards everything
else. The APT repository at https://dedupcommando.github.io/apt/ is the separate repository
[dedupcommando/apt](https://github.com/dedupcommando/apt) and does not change.
